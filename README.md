# huihui_project-v1

## 簡介

My personal website built with HTML, CSS, and JavaScript.

網站內容包含個人介紹、作品展示、貼文卡片、程式碼展示區塊，以及 Tier Maker 互動頁面。

---

## 功能

- Personal homepage
- About / Works / Posts / Contact pages
- Multi-language pages
- Code block with Prism.js
- Copy button for code blocks
- Post card layout
- Image gallery
- Image lightbox
- Tier Maker
- PNG export
- Responsive design
- Cloudflare Pages deployment

---

## 使用技術

- HTML
- CSS
- JavaScript
- Prism.js
- GitHub
- Cloudflare Pages

---

## 部署

This website is deployed with Cloudflare Pages.

After pushing changes to GitHub, Cloudflare Pages automatically rebuilds and deploys the site.
