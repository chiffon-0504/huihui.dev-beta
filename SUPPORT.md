# Support

huihui.dev is an open-source personal web project. This repository does not
provide guaranteed individual technical support, response-time service-level
agreements, or general-purpose Cloudflare or GitHub support.

## Bugs

Use the [Bug Report issue form](https://github.com/chiffon-0504/huihui.dev-beta/issues/new?template=bug_report.yml).
Include the affected page or route, expected and actual behavior, and
reproduction steps. Do not include credentials, secrets, personal data, or
sensitive security details.

## Feature requests

Use the [Feature Request issue form](https://github.com/chiffon-0504/huihui.dev-beta/issues/new?template=feature_request.yml).
Keep the proposal focused and explain the problem or motivation it addresses.

## Security vulnerabilities

Do not use public issues or pull requests for suspected vulnerabilities. Use
GitHub's private [Report a vulnerability](https://github.com/chiffon-0504/huihui.dev-beta/security/advisories/new)
flow, as described in [SECURITY.md](SECURITY.md).

## Contribution questions

Read [CONTRIBUTING.md](CONTRIBUTING.md) for development setup, validation,
workflow, multilingual changes, and repository boundaries. For questions
about a proposed contribution, use normal issue or pull request discussion
when appropriate.

## Unsupported requests

The maintainers may not be able to provide one-on-one troubleshooting,
custom hosting or Cloudflare configuration, GitHub account support, or a
guaranteed response time. Legitimate bug reports and focused contribution
questions are still welcome through the channels above.
